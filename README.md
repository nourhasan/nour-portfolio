# 🚀 Modern Portfolio Website

A beautiful, responsive portfolio website built with React, TypeScript, and modern design principles. Features a sleek dark/light theme system that automatically adapts to your system preferences.

## ✨ Features

- 🎨 **Modern UI/UX** - Eye-catching gradient effects and smooth animations
- 🌓 **Smart Theme System** - Auto-detects system theme (light/dark) with manual toggle
- 📱 **Fully Responsive** - Optimized for mobile, tablet, and desktop
- ⚡ **Lightning Fast** - Built with Vite for optimal performance
- 🎯 **Type Safe** - Written in TypeScript for better development experience
- 🎭 **Smooth Animations** - Fade-in effects, hover transitions, and micro-interactions
- 📊 **Dynamic Content** - Easy to update portfolio data via JSON configuration

## 🛠️ Tech Stack

- **Framework:** React 19.2.0
- **Language:** TypeScript 5.9.3
- **Build Tool:** Vite 7.2.4
- **Styling:** SCSS + Bootstrap 5.3.8
- **Icons:** Custom SVG icons
- **Fonts:** Inter & Plus Jakarta Sans (Google Fonts)
